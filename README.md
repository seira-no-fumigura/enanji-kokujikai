淮南子の国字解。菊池晩香（三九郎）が講述した『淮南子国字解』で、序説と、原道訓から要略までの各訓を、解釈を付けて収める。下巻には、淮南小山の招隠士とその評、淮南子の名言、淮南王の伝、淮南子の序跋評などの附録が付く。大正 6 年（1917 年）に早稲田大学出版部が『漢籍国字解全書』追補の第 43・44 巻（上・下）として出した。国立国会図書館の目次の字のままの見出しが付く。巻頭の解題・凡例と目次は入れていない。
